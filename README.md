# Pink Cindy Tattoo

Initial website/admin foundation.

## Files
- `index.html` — public website
- `admin.html` — private dashboard shell (authentication is connected in the next step)
- `styles.css` — brand styling
- `app.js` — public content/booking UI
- `supabase-schema.sql` — database foundation
- `assets/pink-cindy-logo.png` — initial brand logo

## Next step
Create a Supabase project, run `supabase-schema.sql`, then add the project URL and anon key to the frontend. Do not put a Supabase service-role key in the website.

## Important
The current booking form is a front-end foundation. It does not claim to store applications until Supabase is connected.
